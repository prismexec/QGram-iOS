# PrismGram для iOS

PrismGram — клиент Telegram для iPhone с функциями в духе AyuGram.
Он собирается из [Swiftgram](https://github.com/Swiftgram/Telegram-iOS) (открытый форк
официального Telegram-iOS, сейчас на базе Telegram 12.9.2), поверх которого накладываются
патчи PrismGram.

В репозитории нет копии исходников Telegram (это ~30 000 файлов). Вместо этого здесь лежит
«набор сборки»: workflow сам скачивает Swiftgram на зафиксированном коммите, накладывает
патчи и собирает IPA.

## Функции

Всё, что уже есть в Swiftgram (скрытие историй, ID и дата регистрации в профиле, переводчик,
настройка контекстного меню, компактный список чатов и т.д.), плюс функции PrismGram:

| Функция | Что делает |
|---|---|
| 👻 Режим призрака | Один переключатель включает все пункты ниже |
| Не отправлять прочтение | Вы читаете сообщения, а у собеседника они остаются непрочитанными (включая треды, форумы, голосовые и кружки) |
| Не отправлять «в сети» | Клиент всегда сообщает серверу «не в сети» |
| Не отправлять «печатает» | Собеседник не видит «печатает…», «записывает голосовое», «отправляет фото» |
| Не отмечать истории просмотренными | Истории открываются без отметки о просмотре |
| Читать при ответе | В режиме призрака: когда вы пишете в чат, он отмечается прочитанным у собеседника (ответ всё равно это выдаёт) |
| 👻 Отправить прочтение | Удерживайте чат в списке или входящее сообщение в чате → прочтение уйдёт собеседнику, даже если режим призрака включён |
| Быстрое включение | Удерживайте вкладку «Чаты» → «👻 Включить / Выключить режим призрака» |
| Офлайн после отправки | Telegram ставит «в сети» при отправке сообщения; PrismGram сразу возвращает «не в сети» |
| Сохранять удалённые сообщения | Удалённые собеседником сообщения остаются в чате — полупрозрачными, с меткой 🗑 (кроме самоуничтожающихся и «просмотр один раз») |
| Сохранять историю правок | Старые версии изменённых сообщений: меню сообщения → «История правок» |
| Скрывать рекламу в каналах | Не загружает спонсорские сообщения |
| Чаты и сообщения | Секунды во времени, ID и дата-центр в профиле, скрыть истории и реакции, отправка по Enter, компактный список и др. |
| Приватность | Скрывать номер в настройках, подтверждение звонков |
| Скорость | Ускоренная отправка и загрузка файлов |

Все переключатели: **Настройки → PrismGram** — отдельное меню только с функциями PrismGram.

В приложении нет упоминаний Swiftgram: экран настроек Swiftgram, Swiftgram Pro, их иконки и тексты убраны,
а обращения к серверам Swiftgram (их API, удалённые настройки, загрузка переводов) отключены.

Важно знать:
- Удалённые сообщения и история правок сохраняются только для сообщений, которые
  приложение уже успело загрузить до удаления/правки. Сервер Telegram удалённое не хранит.
- Telegram сам ставит статус «в сети», когда вы отправляете сообщение. Это клиент изменить не может.
- Изменение статуса «в сети» применяется в течение ~30 секунд.

## Версии

Версия и Bundle ID PrismGram задаются в [`prismgram/app.json`](prismgram/app.json):
`"version": "1.0.0"`, `"bundle_id": "com.prism.prismgram"`. Для нового релиза поменяйте `version`
(например, на `1.1.0`) и запушьте. Номер сборки (3751, 3752…) растёт сам с каждым запуском —
по нему OTA понимает, что вышло обновление.

## Обновления (OTA)

PrismGram сам проверяет новые сборки (не чаще раза в 6 часов) и показывает окно
«Доступно обновление» с кнопкой «Скачать». Вручную: **Настройки → PrismGram → Проверить обновления**.
Отключить: там же, «Сообщать о новых версиях». Установить новую версию нужно через Feather или
другой подписыватель: iOS не даёт приложению обновить само себя без подписи разработчика.

## Как это устроено

| Путь | Что это |
|---|---|
| [`prismgram/upstream.json`](prismgram/upstream.json) | Репозиторий и коммит Swiftgram, на котором собирается PrismGram |
| [`prismgram/patches/`](prismgram/patches) | Код функций PrismGram (git-патчи к Swiftgram) |
| [`prismgram/apply_prismgram.py`](prismgram/apply_prismgram.py) | Накладывает патчи, меняет иконку и имя приложения |
| [`prismgram/branding/`](prismgram/branding) | Иконка (призма) |
| [`.github/workflows/build-ipa.yml`](.github/workflows/build-ipa.yml) | Сборка IPA в GitHub Actions |

## Сборка в GitHub Actions

Workflow запускается сам при пуше в `main` или ветки `claude/**`, если менялись `prismgram/**`
или сам workflow. Вручную: **Actions → Build PrismGram IPA → Run workflow**.

- Раннер `macos-26`, Xcode 26.2 (берётся из `versions.json` Swiftgram).
- Первая сборка идёт долго (2–5 часов). Кэш Bazel сохраняется, следующие сборки быстрее.
- Сначала быстрая проверка на Linux (патчи накладываются, синтаксис Swift в порядке), потом сама сборка.
- Готовый файл публикуется в **Releases**. Постоянная ссылка на последнюю версию:
  `https://github.com/prismexec/QGram-iOS/releases/latest/download/PrismGram.ipa`
  (дублируется в Artifacts → PrismGram-ipa).

### Источник для Feather / AltStore

Добавьте в Feather (Sources → +) ссылку:

```
https://github.com/prismexec/QGram-iOS/releases/latest/download/source.json
```

Feather будет сам показывать новые сборки PrismGram.

### Секреты (окружение `P`: Settings → Environments → P)

| Секрет | Зачем |
|---|---|
| `TG_API_ID` | ваш api_id с [my.telegram.org/apps](https://my.telegram.org/apps) |
| `TG_API_HASH` | ваш api_hash оттуда же |

Без них сборка использует ключи из конфигурации Swiftgram и выводит предупреждение.
Свои ключи лучше завести: это ваш собственный клиент.

### Установка на iPhone

IPA подписан тестовым сертификатом и напрямую не установится. Переподпишите его при установке:
Feather / ESign со своим .p12, [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io)
(подойдёт бесплатный Apple ID, приложение работает 7 дней), либо TrollStore.

Через Feather:
1. Sources → + → вставьте ссылку на источник (см. выше) или импортируйте `PrismGram.ipa`.
2. При подписи выберите свой сертификат (.p12 + профиль).
3. Если на телефоне стоит официальный Telegram, в настройках подписи смените Bundle ID
   (например, на `com.<имя>.prismgram`), иначе установка конфликтует с ним.
4. Перед установкой новой версии со старым Bundle ID удалять старую не нужно — данные сохранятся.

Сборка рассчитана на такую переподпись: iCloud и Siri выключены (иначе приложение вылетает
при запуске без этих разрешений), а если подписыватель убрал App Group, данные хранятся
в папке самого приложения. Что при этом не работает: push-уведомления (обычно нет в профиле),
виджеты и «Поделиться в PrismGram».

## Локальная сборка (macOS + Xcode 26.2)

```bash
git clone https://github.com/Swiftgram/Telegram-iOS.git swiftgram
cd swiftgram
git checkout cf8b23beaaac4126a396337ac2d5be13f9f76b66
git submodule update --init --recursive
python3 /путь/к/этому/репо/prismgram/apply_prismgram.py .
# дальше — как в README Swiftgram (build-system/Make/Make.py build ...)
```

## Обновление на новую версию Swiftgram

1. Поменять `commit` в `prismgram/upstream.json`.
2. Если патч перестал накладываться (скрипт сообщит об этом), применить его вручную
   с `git apply --3way`, поправить конфликты и пересохранить через `git diff`.
